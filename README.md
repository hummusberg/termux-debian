## This script installs and setups Debian for Android. This script requires root. If want a non-root option try [Andronix](https://github.com/andronixApp/AndronixOrigin)
## Installation

To install Debian run install-debian.sh without root.

To launch it run launch-debian.sh with root.

Do not touch setup-debian.sh.

## Autorun

When you use launch-debian.sh it will run autorun.sh in debian. Autorun is in / directory. Use it to set up launch apps and daemons.

## Usage

Sudo won't work in debian use the root account for root.

Use su - username to login as user

You will not have a init system. Use autorun.sh instead.

If you spot a error please make a report on Github.
